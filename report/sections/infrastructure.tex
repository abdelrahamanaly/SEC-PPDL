\subsection{CI/CD Pipeline}

A \texttt{.gitlab-ci.yml} at the repository root defines a 3-stage pipeline:

\begin{enumerate}[nosep]
  \item \textbf{Build}: Docker image build and cache.
  \item \textbf{Test (CPU)}: Automatic on every push. Requires GitLab runners tagged \texttt{docker} + \texttt{amd64}. Runs \texttt{docker compose up} and asserts 7 passed, 0 failed.
  \item \textbf{Test (GPU)}: Manual trigger, \texttt{allow\_failure: true}. Requires \texttt{docker} + \texttt{amd64} + \texttt{gpu} runner tags.
\end{enumerate}

\subsection{Constraints}

The following constraints were enforced throughout this evaluation:
\begin{itemize}[nosep]
  \item All work happens inside Docker containers. No packages installed on the host.
  \item No modifications to pre-existing containers or images on the testbed.
  \item All containers and images created during evaluation are cleaned up after use.
  \item The host machine is used only for SSH access, file copying, and Docker commands.
\end{itemize}
