\begin{abstract}
This report documents the Docker-based benchmarking infrastructure, test results, and stability validation for the BLB (Breaking the Layer Barrier) framework~\cite{xu2025breaking}.
BLB is a hybrid CKKS homomorphic encryption and multi-party computation system for private Transformer inference, published at USENIX Security 2025.
We present a fully containerized evaluation environment that builds all dependencies from source, runs 7 CPU test binaries covering NTT primitives, HE-based linear operators, PrivCirNet block-circulant layers, and fixed-point secure comparison.
All tests pass consistently across multiple runs with zero memory errors (ASAN/UBSAN) and cross-validated numerical correctness against Python reference implementations.
\end{abstract}
